<p style="text-align:center; font-size:1.15rem; margin-top:0.5rem;">
Map every LED in an addressable-LED installation in 3D — with just a phone —
then design light effects that flow across the real geometry and play them live
on the controller.
</p>

This is the **developer** documentation: how splanc is built, how the pieces fit
together, and how to work on each subsystem. If you just want to _use_ the app,
start at the [live PWA](https://ledmapper.pages.dev) — nothing to install.

Everything here (including the generated figures and animations below) is
regenerated by a single Bazel target:

```sh
bazel run //docs:build
```

See {doc}`about-these-docs` for how that works.
