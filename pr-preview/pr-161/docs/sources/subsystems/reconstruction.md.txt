# Reconstruction (`pi/reconstruction/`)

The M3 reconstruction: it turns a batch of 2D detection records — the same LED
seen from many camera poses — into a per-LED 3D position. DLT triangulation
seeds each point, a sparse **Huber bundle adjustment** refines all positions
jointly, outliers are rejected, and the result is quality-scored and emitted as
an `OutputMap`. It is the Python reference the Rust {doc}`solver` is a port of.

## Key files

- `reconstruction/api.py` — `reconstruct(detections, ...) -> OutputMap`, the
  public entry point.
- `reconstruction/triangulate.py` — DLT triangulation and parallax.
- `reconstruction/bundle.py` — the sparse bundle adjustment.
- `reconstruction/camera.py` — the pinhole camera model (shared with the
  simulator).
- `reconstruction/vio.py`, `vio_api.py`, `vio_replay.py` — the joint
  visual-inertial solve and offline replay (see {doc}`../design/index`).

## Run

```sh
# Reconstruct a map from a detection log:
bazel run //pi/reconstruction:reconstruct -- session.json -o map.json

bazel test //pi/reconstruction:reconstruct_test
bazel test //pi/reconstruction:rust_parity_test   # parity with solver/
```
