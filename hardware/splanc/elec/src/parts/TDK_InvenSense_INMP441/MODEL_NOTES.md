# Simplified package visualization

Generated by hardware/tools/make_splanc_package_models.py from the package
envelope dimensions in https://invensense.tdk.com/wp-content/uploads/2015/02/INMP441.pdf.

This is a simplified CAD model for rendering: no manufacturer markings,
internal geometry, solder fillets or detailed lead profiles. Use the manufacturer's
mechanical drawing for clearance/tolerance review. The microphone's bottom
acoustic opening is represented by the PCB footprint and is not cut into this
simplified package body. This is not a photograph of an assembled unit.
